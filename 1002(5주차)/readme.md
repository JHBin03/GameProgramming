## 수업 자료 외의 내용

- 모든 것을 함수로 처리한다. 함수의 종류는 다양하다.
- `scanf` -> 버퍼를 비우지 못해 의도대로 작동하지 않는 문제가 있다는 점을 강조한다. 스크린샷에는 사용자가 많아 남겨졌다는 이야기도 적혀 있다.
- 키보드 입력 -> ASCII code와 scan code 두 가지가 있다. 방향키 입력을 강조한다.

## 음계와 피아노 건반

- 저장된 음원 재생 대신 주파수로 기계적인 음을 표현한다.
- 주파수가 높으면 고음, 낮으면 저음이 난다.
- 음계(musical scale) -> 음을 높이 순서로 늘어놓은 것
- 음정(tone) -> 음 높이의 차이
- 절대음정의 기준 -> 라(A), 440Hz
- 다른 음의 주파수는 라(A)를 기준으로 계산한다.
- 평균율 -> 한 옥타브를 같은 비율로 나눈 음률
- 12평균율 -> 한 옥타브를 12개의 반음정(semitone)으로 나눈다.
- 옥타브의 음정비 -> 1:2. 한 옥타브 위의 도는 아래 도 주파수의 두 배이다.

## 음계의 주파수

- 반음 사이의 주파수 비 -> `2^(1/12) : 1`, 약 `1.0594 : 1`
- 위 음으로 이동 -> 주파수에 비율을 곱한다.
- 아래 음으로 이동 -> 주파수를 비율로 나눈다.
- 한 옥타브 아래 -> 주파수 `/ 2`, 한 옥타브 위 -> 주파수 `* 2`
- 주파수 표는 소수 첫째 자리에서 반올림한 값을 사용한다.
- 옥타브 1의 도(C) -> 표에서는 33Hz, 계산 기준값은 32.7032Hz
- 옥타브 2의 도(C) -> `32.7032 * 2 = 65.4064Hz`

## 주파수 출력

- `print_frequency(int octave)` -> 해당 옥타브의 음계별 주파수를 출력한다.
- `do_scale = 32.7032` -> 옥타브 1의 도 주파수
- `ratio = pow(2., 1/12.)` -> 반음 사이의 주파수 비
- `temp = do_scale * pow(2, octave-1)` -> 해당 옥타브의 도 주파수
- 12번 반복하며 주파수를 출력하고 `temp *= ratio`로 다음 음을 계산한다.
- `(unsigned long)(temp+0.5)` -> 반올림한 정수로 출력한다.
- `main` -> 음계 이름과 구분선을 출력한 뒤 옥타브 1~6의 주파수를 출력한다.

## 주파수를 이용한 음의 출력

- Turbo C의 `sound` -> 주파수로 컴퓨터 스피커의 소리를 낸다.
- Visual C++의 `Beep` -> 주파수와 지속시간으로 소리를 낸다.
- `Beep`는 Win API 함수이다. ANSI C 표준함수가 아니다.
- 필요한 헤더 -> `<windows.h>`
- `Beep(dwFreq, dwDuration)`
  - `dwFreq` -> 소리의 주파수. 37~32,767 범위
  - `dwDuration` -> 지속시간. 단위는 밀리초
  - 정상 실행 -> 0이 아닌 값을 반환한다.
- 옥타브 4에서 반음을 제외한 예 -> 각 음을 500ms(0.5초)씩 출력한다.

| 음계 | 도 | 레 | 미 | 파 | 솔 | 라 | 시 | 도(위) |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 주파수(Hz) | 262 | 294 | 330 | 349 | 392 | 440 | 494 | 523 |

## 주파수 계산

- `calc_frequency(int octave, int inx)` -> 음계의 주파수를 정수형으로 반환한다.
- 첫 번째 매개변수 -> 옥타브
- 두 번째 매개변수 -> 계산할 음계의 index
- `index[] = {0, 2, 4, 5, 7, 9, 11, 12}` -> 도#, 레#, 파#, 솔#, 라#을 제외한 도레미파솔라시도
- 예: `calc_frequency(4, index[0])` -> 옥타브 4의 도
- 해당 옥타브의 도 주파수에서 시작해 `inx`번 반복한다.
- 반복문 안에서 `temp = (int)(temp+0.5)` 후 `temp *= ratio`를 수행한다.
- 마지막에 `(int)temp`를 반환한다.

## 스피커로 소리내기

- 옥타브 4의 주파수 8개를 계산해 `freq[8]`에 저장한다.
- `Beep(freq[i], 500)` -> 한 음을 0.5초씩 출력한다.
- 도레미파솔라시도 -> `Sleep(1000)`으로 1초 대기 -> 도시라솔파미레도
- 실행 중 화면 출력은 없다.

## 숫자 키에 따라 음 출력

| 숫자 키 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 음계 | 도 | 레 | 미 | 파 | 솔 | 라 | 시 | 도(위) |
| 배열 위치 | `index[0]` | `index[1]` | `index[2]` | `index[3]` | `index[4]` | `index[5]` | `index[6]` | `index[7]` |

- `practice_piano()` -> 숫자 키에 해당하는 음을 출력한다.
- `scanf` -> 숫자 입력 후 Enter가 필요해 음의 연결이 자연스럽지 않다.
- `getch()` -> Enter 없이 입력받는다. 숫자 키도 문자로 입력받는다.
- `'1' <= code && code <= '8'` -> 1~8 키만 음을 출력한다.
- `code -= 49` -> 문자 '1'을 배열 첨자 0으로 바꾼다.
- `Beep(freq[code], 300)` -> 해당 음을 300ms 동안 출력한다.
- `code != 27`인 동안 반복한다. Esc키로 종료한다.
- `main` -> 숫자 키별 음계와 종료 방법을 안내하고 `practice_piano()`를 호출한다.

## 자료 구조

- 자료 구조(data structure) -> 데이터와 데이터 사이의 상호 관계를 정의하는 것
- 데이터를 효율적으로 탐색·추가·삭제하기 위한 저장 방법과 연결 방법을 다룬다.
- 선형 구조 -> 연결 리스트(linked list), 스택(stack), 큐(queue), 데크(dequeue)
- 비선형 구조 -> 트리(tree), 그래프(graph)

## 연결 리스트와 replay

- 연결 리스트의 데이터는 노드(node)에 저장한다.
- 노드 -> 데이터 필드(data field) + 링크 필드(link field)
- 데이터 필드 -> 데이터 저장
- 링크 필드 -> 다음 노드를 가리킨다.
- 게임 중에 발생하는 데이터를 어떻게 저장할 것인가?
  - 버튼 조작이 있을 때마다 필요한 만큼 메모리를 확보한다.
  - 버튼 데이터를 연결 리스트에 순서대로 저장한다.
  - `head` -> 연결 리스트가 시작되는 위치
  - `head`부터 저장된 데이터를 순서대로 읽어 게임을 재연한다.

## 스택

- 스택(stack) -> 데이터의 추가와 삭제가 한쪽에서만 이루어지는 자료 구조
- `top` -> 데이터가 추가되고 삭제되는 위쪽
- 수건 더미 -> 새 수건을 위에 올리고, 가져갈 때도 맨 위부터 가져간다.

## 동적 메모리 관리

- 배열의 문제 -> 크기를 미리 정해야 한다.
- 정한 크기보다 적게 사용하면 메모리를 낭비한다.
- 실행에 필요한 만큼 기억 공간을 확보해야 한다.
- 정보가 생성될 때 -> 해당 정보에 맞는 데이터 형으로 메모리에 저장한다.
- 정보가 필요 없어질 때 -> 다른 정보를 저장하도록 메모리 공간을 돌려준다.
- 동적 메모리 관리(dynamic memory management) -> 동적 할당(dynamic allocation)과 반환(deallocation)을 이용한다.
