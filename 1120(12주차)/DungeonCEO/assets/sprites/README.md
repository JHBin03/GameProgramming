# 스프라이트 제작 기록

내장 ImageGen으로 카툰 스프라이트 시트를 생성해 144 × 144 투명 PNG 52개로 분리했습니다. 윤곽선을 포함해 개체별로 3~5색을 사용하고, 같은 개체의 프레임은 바닥 기준선을 맞췄습니다. 몬스터와 함정의 `idle` 프레임은 방과 구매 목록에서 함께 사용합니다.

## ImageGen 프롬프트

모든 시트에 투명 배경, 칸별 여백, 굵고 어두운 윤곽선, 단색 면 3~5개, 42px에서 읽히는 단순한 카툰 실루엣을 지정했습니다.

- 몬스터 5열 × 4행. 슬라임, 스켈레톤, 좀비, 동굴 고블린, 그림자 늑대와 오크 광전사, 흑철 골렘, 미노타우로스, 심연의 리치, 와이번을 각각 대기 행과 왼쪽 공격 행에 배치.
- 용사 4열 × 4행. 파란 전사, 초록 궁수, 진홍 암살자, 보라 마법사의 대기, 걷기 두 자세, 오른쪽 공격을 생성. 걷기는 같은 복장을 참조한 4열 × 2행 시트에서 넓은 보폭과 한쪽 다리로 지탱하며 다른 발을 들어 올린 자세로 다시 생성.
- 함정 4열 × 4행. 가시 바닥, 쇠약 안개 향로, 광란의 깃발, 현상금 인장과 수집가의 제단, 부활의 관, 역행의 문, 종말의 각인을 각각 대기 행과 발동 행에 배치.
