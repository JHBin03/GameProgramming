# PDF 3 (19페이지까지) 
## 꼬리 재귀(Recursive Function)
- 꼬리 재귀란 재귀 함수에서 재귀 호출이 함수의 마지막 연산이 되는 형태
- 일반 재귀와 달리, 꼬리 재귀는 컴파일러가 최적화하면 반복문처럼 실행할 수 있다
- PDF의 Serial Number가 꼬리 재귀의 예시
``` C
void serial_number(long number)
{
    if (number > 0)
    {
        serial_number(number / 10);
        printf("%ld\n", number % 10);
    }
    else
        return;
}
```
## DX(디지털 전환)
- 아날로글 중심의 업무와 시스템을 디지털 기술 기반으로 전환하는 것.
## AX(AI 전환)
- 인공지능을 업무와 시스템에 도입하여 의사결정과 작업 과정을 혁신하는 것.

## DX와 AX의 관계
- DX는 AX를 도입하기 위한 중요한 기반이 된다.
- 디지털 데이터와 시스ㅔㅁ이 충분히 구축되어 있으면 AX를 도입하기 유리하다.

## 디지털 숫자 만들기
- 배열구조와 인덱스 계산을 이해한다.
- 숫자 0~9를 각각 배열에 저장하고, 배열의 값에 따라 모양 출력.
- 하나의 숫자는 5행 X 4열 = 20개의 요소로 표현한다.

## 이중 포인터
- 더블 포인터라고도 부른다.
- 포인터 변수의 주소를 저장한다.
## 포인터와 이중 포인터의 차이

| 구분       | 포인터 (Pointer)     | 이중 포인터 (Double Pointer)         |
| -------- | ----------------- | ------------------------------- |
| 1. 저장 대상 | 일반 변수의 주소 저장      | 포인터 변수의 주소 저장                   |
| 2. 선언 방식 | `int *p;`         | `int **pp;`                     |
| 3. 주요 용도 | 변수의 값에 간접 접근 및 수정 | 함수에서 포인터 자체를 수정하거나 다중 포인터 구조 관리 |

## 포인터를 왜 쓰는가?
- 변수의 메모리 주소를 통해 데이터를 읽거나 수정할 수 있다.
- 크기가 큰 데이터를 복사하지 않고 전달하여 불필요한 복사를 줄인다.
- 프로그램 실행 중 필요한 만큼 메로리를 할당하고해제할수 있다.
- 함수에 변수의 주소를 전달하여 호출한 쪽의 원본 데이터를 수정할 수 있다.
- 연결 리스트, 트리, 그래프 등의 동적 자료구조를 구현할 수 있다.
## 포인트의 리스크
- NULL 포인터를 역참조하면 프로그램이 비정상 종료되거나 정의되지 않은 동작이 발생할 수 있다.
- 이미 해제된 메모리를 가리키는 포인터로 잘못 접근하면 위험하다.
- 동적으로 할당한 메모리 범위를 벗어나 접근하면 다른 데이터를 손상시킬 수 있다.
- 같은 메모리를 두 번 해제하면 정의되지 않은 동작이 발생할 수 있다.
- 메모리 주소를 직접 관리하므로 오류의 원인을 파악하기 어렵다.
## Rust
- 포인터의 위험성을 줄이기 위한 언어이다.
- 주로 C/C++엣서 발생하기 쉬운 메모리 안전성 문제를 줄이도록 설계되었다.
