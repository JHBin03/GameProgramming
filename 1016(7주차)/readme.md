## 숫자의 변환과 표현

### 숫자의 자리 분리

- 정수의 각 자리 숫자를 출력하는 방법 -> 높은 자리부터 출력 / 낮은 자리부터 출력
- 예시 `756896`
  - 높은 자리부터 -> `7 5 6 8 9 6`
  - 낮은 자리부터 -> `6 9 8 6 5 7`

### 정수와 문자열

- `123` -> 정수. 사칙연산 등 산술 연산에 사용한다.
- `"123"` -> 문자열. `number[0]`, `number[1]`처럼 문자 단위로 접근한다.
- 문자열 입력 -> `char number[]`에 저장하고 `strlen()`으로 길이를 구한다.
- 문자열은 인덱스를 순서대로 읽으면 높은 자리부터, 역순으로 읽으면 낮은 자리부터 출력한다.
- 문자열 끝에는 널 문자 `\0`이 들어간다.

```c
char number[] = "123";
printf("%c\n", number[0]); // '1'
```

- PDF 4p의 역순 예제는 `i=length`에서 시작한다. 이 경우 첫 번째로 `\0`에 접근하므로 실제 숫자를 역순 출력할 때는 `length - 1`부터 시작해야 한다.

### 정수형 숫자 분리

- 정수는 문자열처럼 인덱스로 자릿수를 읽을 수 없다.
- `/` -> 자릿수 분리, `% 10` -> 일의 자리 추출.
- `number /= 10` -> 마지막 자리 제거.
- 높은 자리부터 출력 -> `log10()`으로 자릿수를 구하고 `pow(10, i-1)`로 나누는 방식.
- 낮은 자리부터 출력 -> `% 10`으로 출력한 뒤 `/ 10`을 반복한다.

```c
void reverse_number(long number)
{
    while (number > 0)
    {
        printf("%ld\n", number % 10);
        number /= 10;
    }
}
```

## 재귀적 호출 (Recursive Function)

- 재귀 함수 -> 함수 내부에서 자기 자신을 다시 호출하는 함수.
- 종료 조건이 필요하다. 종료 조건이 없으면 호출이 계속될 수 있다.
- 높은 자리부터 출력 -> 먼저 재귀 호출하고, 함수가 돌아오면서 `printf()` 실행.
- 낮은 자리부터 출력 -> 먼저 `printf()` 실행하고, 다음 자리에서 재귀 호출.

### 높은 자리부터 출력: `serial_number()`

```c
void serial_number(long number)
{
    if (number > 0)
    {
        serial_number(number / 10);
        printf("%ld\n", number % 10);
    }
    else
        return;
}
```

- 입력 `123` -> 호출 `123 → 12 → 1 → 0` -> 복귀하면서 `1 → 2 → 3` 출력.
- 재귀 호출 뒤에 `printf()`가 남아 있다.
- **주의: 이 함수는 꼬리 재귀가 아니다.**

### 낮은 자리부터 출력: `reverse_number()`

```c
void reverse_number(long number)
{
    printf("%ld\n", number % 10);
    if ((number / 10) > 0)
        reverse_number(number / 10);
    else
        return;
}
```

- 입력 `123` -> `3 → 2 → 1` 출력.
- 다음 재귀 호출 전에 출력한다.

### 꼬리 재귀 (Tail Recursion)
- 꼬리 재귀 -> 재귀 호출 뒤에 추가 작업 없이 함수가 종료되는 형태.
- 컴파일러가 꼬리 호출 최적화(Tail Call Optimization)를 지원하는 경우 반복문처럼 최적화될 수 있다. 항상 최적화되는 것은 아니다.
- PDF의 `serial_number()`는 **재귀 호출 다음에 출력문이 있으므로 꼬리 재귀 예시가 아니다.**
- PDF의 낮은 자리 출력 `reverse_number()`는 재귀 호출 뒤에 수행할 작업이 없어 꼬리 재귀 형태에 가깝다.

## 디지털 숫자

### 배열로 숫자 표현

- `0~9`의 숫자 모양을 각각 1차원 배열에 저장한다.
- 숫자 하나 -> **5행 × 4열 = 20개 요소**.
- 배열 값 `1` -> `■` 출력, `0` -> 공백 출력.
- 1차원 배열의 인덱스로 5행의 숫자 모양을 나눠 출력한다.

| 행 (`line`) | 사용하는 배열 인덱스 |
| --- | --- |
| 0 | 0~3 |
| 1 | 4~7 |
| 2 | 8~11 |
| 3 | 12~15 |
| 4 | 16~19 |

- `line * 4` -> 해당 줄의 시작 인덱스.
- `line * 4 + 3` -> 해당 줄의 마지막 인덱스.

### 함수 역할

- `number_check(int k, int i)` -> 입력된 숫자를 자릿수별로 분리하고 각 숫자 배열을 선택한다.
- `digit_print(int dim[], int line)` -> 선택된 숫자 배열에서 지정된 행만 출력한다.
- `main()` -> `line=0`부터 `4`까지 반복하며 `number_check()` 호출.
- `number_check()`는 **재귀 호출을 먼저** 수행 -> 숫자의 높은 자리부터 가로로 출력한다.
- `k % 10` -> 현재 자리 숫자. `switch`에서 `zero`~`nine` 배열을 선택한다.

```c
void digit_print(int dim[], int line)
{
    int i;
    for (i = line * 4; i <= line * 4 + 3; i++)
    {
        if (dim[i] == 1)
            printf("■");
        else
            printf(" ");
    }
    printf(" ");
}
```

```c
void number_check(int k, int i)
{
    if (k >= 1)
    {
        number_check(k / 10, i);
        switch (k % 10)
        {
            case 0: digit_print(zero, i); break;
            case 1: digit_print(one, i); break;
            case 2: digit_print(two, i); break;
            case 3: digit_print(three, i); break;
            case 4: digit_print(four, i); break;
            case 5: digit_print(five, i); break;
            case 6: digit_print(six, i); break;
            case 7: digit_print(seven, i); break;
            case 8: digit_print(eight, i); break;
            case 9: digit_print(nine, i); break;
        }
    }
}
```

- 위 코드는 **PDF의 함수 구조를 뽑은 일부**이다. `zero`~`nine` 배열 선언은 생략했다.
- PDF 19p는 `1` 이상의 정수를 입력받는다. 위 방식은 입력이 `0`일 때 숫자를 출력하지 않는다.

### 포인터 (Pointer)

- 포인터 -> 메모리 주소를 저장하는 변수.
- `&` -> 변수의 주소를 구한다.
- `*` -> 포인터가 가리키는 대상에 접근한다(역참조).

### 포인터와 이중 포인터 (Double Pointer)

| 구분 | 포인터 | 이중 포인터 |
| --- | --- | --- |
| 저장 대상 | 일반 변수의 주소 | 포인터 변수의 주소 |
| 선언 | `int *p;` | `int **pp;` |
| 주요 용도 | 원본 값에 간접 접근·수정 | 함수에서 포인터 자체를 수정하거나 포인터 구조 관리 |

```c
int n = 10;
int *p = &n;
int **pp = &p;
// *p와 **pp는 모두 n의 값에 접근한다.
```

### 포인터를 쓰는 이유

- 주소를 이용해 데이터를 읽거나 수정한다.
- 큰 데이터를 복사하지 않고 함수에 전달한다.
- 실행 중 필요한 크기로 메모리를 할당하고 해제한다.
- 함수에 주소를 전달해 호출한 쪽의 원본 값을 수정한다.
- 연결 리스트, 트리, 그래프 등의 동적 자료구조를 구현한다.

### 포인터의 위험성

- `NULL` 포인터 역참조 -> 정의되지 않은 동작(비정상 종료 등).
- 해제된 메모리를 다시 접근 -> 잘못된 메모리 접근.
- 할당된 메모리 범위 밖에 접근 -> 데이터 손상 가능.
- 같은 메모리를 두 번 해제 -> 정의되지 않은 동작.
- 메모리 주소를 직접 관리하므로 오류 추적이 어렵다.
