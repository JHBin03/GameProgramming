## 1. ASCII Code와 Scan Code

### ASCII Code란?
ASCII Code는 컴퓨터가 문자를 처리하거나 전송하기 위해 사용하는 코드 체계임.

예를 들어 문자 `a`를 입력하면 컴퓨터는 문자 자체를 그대로 처리하는 것이 아니라, `a`에 대응하는 코드 값을 이용함.

즉, ASCII Code는 **문자를 숫자로 표현하기 위한 규칙**이라고 볼 수 있음.

---

### Scan Code란?
Scan Code는 **키보드의 각 키(key)에 대응하는 코드 값**임.

즉, 문자 자체보다는 **어떤 키가 눌렸는지 구분하기 위해 사용하는 값**임.

예를 들어 방향키는 다음과 같은 Scan Code를 사용함.

| 키 | Scan Code |
|---|---:|
| 위쪽 방향키 | 72 |
| 왼쪽 방향키 | 75 |
| 오른쪽 방향키 | 77 |
| 아래쪽 방향키 | 80 |

---

### Scan Code는 왜 필요한가?
키보드에는 문자만 존재하는 것이 아님.

예를 들어 다음과 같은 키가 존재함.

- 방향키
- Home
- End
- Page Up
- Page Down

이러한 키는 일반적인 문자처럼 ASCII Code만으로 표현하기 어려움.

따라서 **어떤 키가 눌렸는지 구분하기 위해 Scan Code를 사용함.**

게임에서는 방향키 입력을 통해 캐릭터를 이동시키는 경우가 많기 때문에 Scan Code가 중요함.

---

### 왜 ASCII Code와 Scan Code를 비교하는가?
ASCII Code와 Scan Code는 모두 키보드 입력과 관련되어 있지만 역할이 다름.

| 구분 | ASCII Code | Scan Code |
|---|---|---|
| 기준 | 문자 | 키보드의 키 |
| 목적 | 어떤 문자인지 표현함 | 어떤 키가 눌렸는지 구분함 |
| 예 | `A`, `a`, `1` | 방향키, Home, End |
| 게임에서의 활용 | 문자 입력 처리 | 이동키 처리 |

따라서 프로그램에서는 입력된 값이 일반 문자 입력인지, 방향키 같은 확장키 입력인지 구분해야 함.

수업 자료에서는 `getch()`를 이용하여 이를 구분함.

```c
chr = getch();

if (chr == 0 || chr == 0xe0)
{
    chr = getch();
    printf("확장키 code=%d\n", chr);
}
else
{
    printf("아스키 code=%d\n", chr);
}
```

확장키를 입력하면 첫 번째 `getch()`에서 `0` 또는 `224(0xE0)`가 반환됨.

이후 `getch()`를 한 번 더 호출하면 실제 확장키 코드를 얻을 수 있음.

## 2. 방향키 입력과 좌표 이동

방향키의 Scan Code를 이용하여 화면상의 `x`, `y` 좌표를 변경함.

```c
switch(key)
{
case 72:
    *y1 = *y1 - 1;
    break;

case 75:
    *x1 = *x1 - 1;
    break;

case 77:
    *x1 = *x1 + 1;
    break;

case 80:
    *y1 = *y1 + 1;
    break;
}
```

방향별 좌표 변화는 다음과 같음.

| 방향 | 좌표 변화 |
|---|---|
| 위 | `y--` |
| 아래 | `y++` |
| 왼쪽 | `x--` |
| 오른쪽 | `x++` |

---

## 3. 좌표 범위 제한

캐릭터나 문자가 화면 밖으로 이동하지 않도록 좌표의 최소값과 최대값을 제한함.

```c
if (*y1 < 1)
    *y1 = 1;
```

위 코드는 `y` 값이 1보다 작아지면 다시 1로 설정함.

오른쪽과 아래쪽도 같은 방식으로 최대 범위를 제한함.

```c
if (*x1 > x_b)
    *x1 = x_b;

if (*y1 > y_b)
    *y1 = y_b;
```

즉, 화면 범위를 벗어나지 않도록 좌표를 보정함.

---

## 4. 방향키로 문자 이동시키기

수업 자료에서는 화면에 문자 `A`를 출력하고 방향키 입력에 따라 위치를 이동시킴.

```c
#define X_MAX 79
#define Y_MAX 24
```

`X_MAX`, `Y_MAX`는 이동 가능한 최대 좌표를 의미함.

초기 위치를 설정함.

```c
int x = 10, y = 5;
```

현재 좌표에 `A`를 출력함.

```c
gotoxy(x, y);
printf("A");
```

키 입력을 받음.

```c
key = getch();
```

입력된 방향키에 따라 좌표를 변경함.

```c
move_arrow_key(key, &x, &y, X_MAX, Y_MAX);
```

ESC 키 코드인 `27`이 입력될 때까지 반복함.

```c
do
{
    ...
} while(key != 27);
```

이 과정은 게임의 기본적인 **입력 → 좌표 변경 → 화면 출력** 구조와 연결됨.

## 5. 사각형 그리기

일반적인 컴퓨터 그래픽에서는 좌표와 선을 이용하여 사각형을 그림.

하지만 콘솔의 텍스트 모드에서는 같은 방식으로 표현하기 어려움.

따라서 다음과 같은 선 모양 문자를 연속해서 출력하여 사각형을 표현함.

```text
┌────┐
│    │
└────┘
```

즉, 사각형을 하나의 그림으로 그리는 것이 아니라 여러 문자를 조합하여 표현함.

---

## 6. 정사각형의 표현

정사각형은 다음과 같은 부분으로 나누어 생각할 수 있음.

```text
┌────┐
│    │
│    │
└────┘
```

필요한 요소는 다음과 같음.

- 왼쪽 위 모서리
- 오른쪽 위 모서리
- 왼쪽 아래 모서리
- 오른쪽 아래 모서리
- 가로선
- 세로선
- 내부 공백

수업 자료에서는 확장 완성형 코드 값을 이용하여 선 문자를 출력함.

```c
unsigned char a = 0xa6;
unsigned char b[7];
```

반복문을 이용하여 배열에 값을 저장함.

```c
for(i = 1; i < 7; i++)
    b[i] = 0xa0 + i;
```

## 7. 길이가 n인 표준 정사각형

사용자가 입력한 값 `n`에 따라 정사각형의 크기가 달라지도록 구성함.

```c
scanf("%d", &n);
draw_square(n);
```

`draw_square(n)` 함수에서 전달받은 크기만큼 반복하여 사각형을 출력함.

---

### 윗부분 출력

윗부분은 다음 순서로 출력함.

1. 왼쪽 위 모서리를 출력함.
2. 가로선을 `size`번 반복 출력함.
3. 오른쪽 위 모서리를 출력함.

```c
printf("%c%c", a, b[3]);

for(i = 0; i < size; i++)
    printf("%c%c", a, b[1]);

printf("%c%c", a, b[4]);
```

---

### 중간 부분 출력

중간 부분은 다음 순서로 출력함.

1. 왼쪽 세로선을 출력함.
2. 내부 공백을 `size`번 출력함.
3. 오른쪽 세로선을 출력함.
4. 위 과정을 `size`번 반복함.

```c
for(i = 0; i < size; i++)
{
    printf("%c%c", a, b[2]);

    for(j = 0; j < size; j++)
        printf(" ");

    printf("%c%c", a, b[2]);
    printf("\n");
}
```

바깥쪽 `for`문은 세로 방향의 크기를 담당함.

안쪽 `for`문은 한 줄 내부의 공백 크기를 담당함.

---

### 아랫부분 출력

아랫부분은 다음 순서로 출력함.

1. 왼쪽 아래 모서리를 출력함.
2. 가로선을 `size`번 반복 출력함.
3. 오른쪽 아래 모서리를 출력함.

```c
printf("%c%c", a, b[6]);

for(i = 0; i < size; i++)
    printf("%c%c", a, b[1]);

printf("%c%c", a, b[5]);
```
